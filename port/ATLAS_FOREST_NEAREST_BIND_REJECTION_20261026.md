## Disposition and next distinct gate

**Reject** the full-RGBA nearest co-resident page and runtime mapping: active-camera pixel mismatch and negligible Forest bind reduction. The isolated blank-only test had no pixel drift but cannot reduce binds without a compatible co-resident texture; `edge_fade_top` was not integrated or physically proven, so no universal no-candidate assertion is made. The measured nearest eligible pair offers no shippable gain. Next bounded slice should address normalized UV/filter coordinate precision with a source-pixel-addressed ordinary sampler or select a different actually alternating eligible family from a GL bind trace; require cross-camera synchronized exact pixels before any A/B/A performance acceptance. Keep wrap/private paths dedicated. Broad atlas coverage, 60 FPS, 8K/high-Hz, VRAM/thermal, and release acceptance remain open.
