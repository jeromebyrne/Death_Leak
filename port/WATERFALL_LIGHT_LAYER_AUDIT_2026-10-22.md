# Waterfall-top light/layer source audit — 2026-10-22

Scope: read-only comparison at `68a0385` (`Restore waterfall V autoscroll and flipped UV wrap`); vertical UV autoscroll is excluded. No game/build/GPU/display operation was used. This report is the only file written.

## Highest-confidence next mismatch: unpinned minification filter on ordinary translucent layers

The two authored sun shafts (IDs 46 and 47) are ordinary 512×512 `Sprite`s using `Media/sun_shaft_2.png`, `effectlighttexture`, alpha 1 and `kGroundFront`; the left is X-flipped and both are rotated (`Game/XmlFiles/levels/waterfall_top.xml:796-824`). The texture has a nontrivial RGBA edge (512×512; observed alpha range 0–166, read-only asset inspection). Windows' `BasicLightTexture.fx` directly samples its RGBA and multiplies only alpha (`Game/ShaderFiles/BasicLightTexture.fx:53-59`), with `MIN_LINEAR_MAG_POINT_MIP_LINEAR` filtering (`:10-16`). `Sprite::Draw_effectLightTexture` passes the authored alpha (`Game/src/GameObjects/Sprite.cpp:626-637`). The game's RGB blend is source-alpha-over (`Game/src/Core/Graphics.cpp:392-405`). Thus edge texels are *linearly minified* before source-alpha-over and before the full-scene sepia pass.

The Linux renderer decodes the PNG and creates an SDL texture, sets blend mode, but never sets a texture scale mode (`port/linux/SDLRenderer.cpp:141-169`). Its ordinary shaft path uses `SDL_RenderCopyExF` (`:176-193,230-234`), while `LevelScene` maps the 512-world-unit quad to 341⅓ output pixels at its fixed 2/3 scale and forwards alpha, rotation and flips (`port/game/LevelScene.cpp:903-943`). SDL's default texture scale mode is nearest unless an external hint changes it; no production port code sets `SDL_HINT_RENDER_SCALE_QUALITY` or `SDL_SetTextureScaleMode` (bounded search of `port` excluding build copies; only tests explicitly set nearest). Therefore the production path does **not guarantee** the original's linear minification, and under SDL's default it uses nearest. This is a concrete texture-edge/shaft-opacity fidelity gap, not a claim of an already measured pixel difference. It can change the feather and subpixel intensity of the pale shafts and of other alpha-composited waterfall layers without changing their XML alpha values.

## Layer/alpha cross-check (not additional findings)

- IDs 46/47 are `kGroundFront` in XML; source sorts descending depth (`Game/src/GameObjects/GameObjectManager.cpp:58-64,1021-1025`) and port maps that layer to 1750 then stable-sorts descending (`port/game/LevelScene.cpp:31-41,551,877-879`). No evidence of a shaft draw-order inversion.
- Source shader alpha multiplication and source-alpha-over match the generic port's authored alpha into SDL texture alpha modulation and `SDL_BLENDMODE_BLEND` (`port/game/LevelScene.cpp:490-492,925-929`; `port/linux/SDLRenderer.cpp:165,190-191`). Do not “fix” shaft alpha or switch to additive blending.
- The two pixel-wobble `waterfall_4.png` layers at 0.3 alpha and `kGroundBack` (`Game/XmlFiles/levels/waterfall_top.xml:261-307`) use a separate GL path that already selects `GL_LINEAR` minification (`port/linux/SDLRenderer.cpp:303-325`). This finding specifically targets ordinary `effectlighttexture`/SDL-copy layers, including the sun shafts; it is not a request to revisit V autoscroll.

## Minimal correction and discriminating test proposal

Pin the ordinary SDL texture-copy path's minification to linear, preferably at texture creation for downscaled scene assets, while preserving source-alpha blending, authored alpha, flips, rotation and painter order. Since `SDL_SetTextureScaleMode(..., SDL_ScaleModeLinear)` also changes magnification whereas the original uses point magnification, either apply it only to known minified scene textures or use a narrow GL sampler path that sets `GL_TEXTURE_MIN_FILTER=GL_LINEAR` and `GL_TEXTURE_MAG_FILTER=GL_NEAREST`; do not globally change HUD/pixel-art sampling without review. A focused renderer test can query the created shaft texture's scale mode (and guard the ordinary draw branch), then compare a lossless, matched-camera isolated ID46/47 edge and composite on the physical GPU against a Windows reference. Compare alpha-edge profile before sepia and RGB after sepia; keep camera, output dimensions, shaft rotation and layer neighbors fixed. This audit alone does not establish the visual magnitude or acceptance of that correction.
