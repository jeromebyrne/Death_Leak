## Concrete discrepancies / limits

1. **First rendered frame skips fade-in on the ordinary in-Update kill path.** `Combat::Update` advances existing material emitters at lines 277-282, then processes melee/projectile hits later (`Combat.cpp:476,556`); a new emitter is initialized with each particle `alpha=1` (`ParticleSpray.h:15-23`), and `Draw` uses that alpha (`:83-99`). Thus a newly killed ninja's first painted frame is fully opaque (modulo brightness), despite the configured `.15` fade-in. The next update calculates fade normally. The test exercises a direct `DamageEnemy`, calls a zero-delta update and only checks sprite count, so it does not catch this. Original `ParticleSpray::Update` calculates fade during its update (`Game/src/Particles/ParticleSpray.cpp:150-260`); exact source first-frame manager scheduling was not established here, so this is a concrete port timing artifact and a visual-parity risk, not a proven Windows-frame mismatch.
2. **Backbuffer-dependent scale remains unresolved, not a new regression claim.** The Windows factory multiplies sampled size and speed and the lifetime-size target by `GameScale.X` (`ParticleEmitterManager.cpp:422,478-525`); this port stores unscaled world samples and projects sprite geometry once at 2/3 (`Combat.cpp:216-220`; `ParticleSpray.h:83-92`). That is coherent for the port's 1920×1080-authored world, but the audit's 1280×720 Windows comparison question remains open. The CPU test only checks port source ranges, not matched backbuffer output.
3. **Painter integration is not exercised by the focused test.** The test calls `Combat::Draw` (`ninja_death_effect_test.cpp:67-75`), not the production `LevelScene` unified painter that receives `AppendPainterItems` callbacks (`Combat.cpp:604-611`; `LevelScene.cpp:1012-1040`). The callback captures a pointer into `materialSprays_`; it is safe under the current append-then-draw flow, but would dangle if a combat mutation were inserted between those phases. No such mutation was found in the reviewed flow. Same-depth authored-spray ordering was not proven against an arena capture.
