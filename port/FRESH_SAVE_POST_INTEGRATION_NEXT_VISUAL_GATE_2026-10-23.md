# Fresh-save post-integration next visual gate — 2026-10-23

## Verdict

**Next distinct source-proven visual omission: the idle sword-pull X prompt.** Original Windows displays a player-attached, world-space gamepad X icon in the first intro phase after **strictly more than eight seconds** of total phase time whenever Interact is up. The current Linux fresh-save branch has no phase-total clock or X-icon draw. This is separate from the now-integrated fall/grounded handoff, 40-fps Pull body, burst/projectile and concurrently owned held-pull shake. It was previously identified in `FRESH_SAVE_INTERACT_ICON_PREFLIGHT_2026-10-23.md`; this audit rechecks its priority against the *post-integration* physical captures and current tree. It is a conditional omission, **not a demonstrated missing pixel in the supplied frames**: those captures end at 4.65 s and hold Interact through the transition. Do not claim matched Windows visual parity from them.

## Exact Windows contract and current omission

- `Game/src/GameObjects/Player.cpp:42,991-1000` increments `mTotalTimePullingSword` by gameplay delta whenever the body is `IntroCutscene1`, independent of held state. `Player.cpp:1012-1018,1121-1148` resets only the *continuous held-progress* counter on release; the eight-second phase clock persists. `Player.cpp:1150-1165` zeros the phase clock in `IntroCutscene2` or later. `Player.cpp:1177-1202` draws the icon after `Character::Draw` only when `mTotalTimePullingSword > 8.0f` and raw `IsPressingInteractButton()==false`. Holding hides it immediately; releasing after eight seconds reveals it without a new wait. The threshold is not `>=`.
- `Player.cpp:73-74,1186-1199` uses `Media/UI/gamepad_icons/x_deck.png` at 60×60 world units only on a Steam Deck; otherwise `Media/UI/gamepad_icons/x.png` at 150×90. The centered world position is `(player.x-35, player.y+50)`, depth `kPlayer+0.1`; `Game/src/Utils/DrawUtilities.h:24-66` uses opaque white textured geometry under the world camera. It is **not** an E-key/HUD prompt or an icon selected merely because a controller is connected. The two PNG assets exist in `Game/Media/UI/gamepad_icons/`.
- Current `port/linux/main.cpp:415-418,640-680` enters the fresh-only Looped/Pull branch and tracks `introHeldTime`, but that variable resets on release and is only the 2.75-s pull-progress clock. No independent eight-second intro phase timer exists there. Targeted search of `port/game` and `port/linux` found no `x_deck`, `gamepad_icons/x`, or intro prompt draw. `port/game/LevelScene.cpp:1296-1437` paints the world player at its updated coordinates, while `main.cpp:1203-1206` samples camera shake before the world pass. A new prompt belongs at the player-adjacent world/depth draw seam, consuming the same draw camera/zoom as the body, not in the postprocess-exempt HUD.
