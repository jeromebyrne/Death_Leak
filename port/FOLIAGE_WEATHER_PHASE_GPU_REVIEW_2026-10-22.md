## Limits and handoff

This is a controlled Linux same-state GPU effect check and source-backed transition test, **not** matched-Windows pixel parity or user visual acceptance. ID60 was tested through the CPU scene/render contract but not separately framed on GPU; the scripted waterfall start camera leaves it offscreen. Weather states at 180+ seconds were not visually captured in a fixed-clock A/B. Existing Linux `visualTime_` resets on level load whereas Windows shader time is process-total, so cross-level Windows pose parity remains an independent clock-origin issue. Shared checkpoint/status files and unrelated working changes were not edited.
