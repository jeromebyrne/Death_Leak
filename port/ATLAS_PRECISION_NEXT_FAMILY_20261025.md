## Controlled sampler result

The synthetic source is 37×29 ARGB8888 with varying per-channel texels. A 96×64 page holds exactly the same pixels at offsets (2,2), (3,3), or (4,4), with nearest-edge extrusion. Identical SDL `RenderCopyExF` calls draw a 24.75×19.5 destination at 17° into 256×256 targets; readback compares all pixels. Nearest scale mode: **0 changed pixels at all three offsets**. Linear scale mode: **1, 0, 1 changed pixels**, respectively; largest channel delta **1**. This controlled perturbation holds source texels, geometry, shader path and filter fixed, changing only normalized source-rectangle position on the page. It establishes page-position-sensitive filtering/coordinate arithmetic on this GL path. It does not isolate whether the last bit arises in SDL UV generation, raster interpolation, or driver sampling, and cannot prove a universal shader-side correction. Rock's earlier exact-pixel failure therefore remains unresolved; it must not be promoted.

## Distinct ordinary draw family and gate

`tree2_blur.png` (669×1650) appears in twelve XML `Sprite` references across Forest and Waterfall. Representative references use `effectlighttexture`, no repeat, no animation, no pixel wobble, no foliage sway, zero authored rotation, and authored display dimensions about 1.108× source. Its sibling `tree2.png` is 1338×3300; a candidate two-source page is 2015×3304, within the 4096 ceiling. The ignored test page uses 2-pixel extrusion and byte-identical cropped RGBA. A physical NVE7 SDL OpenGL test rendered the *actual* `tree2_blur` source versus this page's virtual source rectangle at 741.545×1828.923, nearest filtering, zero rotation, on a clipped 1280×720 frame: **0 changed pixels**. This tests an actually eligible draw contract, but only one controlled transform/background. It is **not** runtime-integrated, and no serial route A/B/A, GL draw/bind or latency delta was collected for it. No production candidate passed the required full gate, so no page or renderer code was accepted. `tree2.png` itself may minify and needs separate sampling parity; the large page costs ~26.6 MB RGBA allocation proxy versus ~4.4 MB for blur alone, so residency must be scene-gated. A sensible next bounded action is opt-in runtime tree-blur mapping with isolated build and synchronized Forest/Waterfall A/B/A, then actual GL-call and latency accounting before any acceptance.

## Reproduction

Run on the physical Xorg `:0` GPU with `SDL_VIDEODRIVER=x11`, `SDL_RENDER_DRIVER=opengl`, `/dev/dri`, the X socket and lightdm Xauthority, as the prior rock probe scripts do. `tree_family.cpp` reads local raw RGBA fixtures generated from the two named original PNGs; the test page and original source crop were byte-compared before rendering. Harness output is reproducible under ignored build files.
