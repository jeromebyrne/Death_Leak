## Source-space cell screen

The shared source `Game/Media/levels/waterfall_bottom/cave_background_blur.png` is 1750×1313 RGBA. Exactly 766,341/2,297,750 source texels have alpha zero (33.35%). A cell is conservatively classed transparent only when every alpha texel in its source rectangle **plus a one-texel neighbor on all sides** is zero; this guards the ordinary GL-linear four-tap footprint at interior cell boundaries. At 32px cells, 736/2310 full-source cells (31.86%) qualify. For the recovered five quads, affine UV→emitted-XY mapping, viewport clipping, and polygon area show 231,639.5/506,408.6 screen-pixel-squared of *modeled* five-quad visible area in such cells (45.74%). At 64px cells, the corresponding screen area is 222,963.1 (44.03%) from 335 visible safe cells. These are area estimates, not exact rasterized fragment counts, GL timing, or savings; the alpha-zero condition is source-safe only within the guarded interior.

## Decision

**Reject runtime geometry B at this gate.** There is no exact-safe subdivision/cut proven across the Forest camera, zoom and shake domain. The currently emitted 30 vertices are one SDL batch of five rotated quads. Dropping guarded source cells requires replacing those quads with a large hole-bearing mesh (hundreds of visible cells even at 64px), potentially changing triangle edge ownership, float UV interpolation and sampling at retained colored boundaries, as well as increasing CPU/vertex traffic. A single sampled camera's affine area screen cannot certify these pixel-center/raster and painter invariants for all active frames. The task's conditional prerequisite (“only if exact raster/painter/source proof permits”) is therefore not met. No runtime B, A/B/A pixel gate, p50/p95/p99 improvement, reduced GL submissions/binds, memory saving or release acceptance is claimed. Default atlas coverage remains 23/896.

Next distinct in-scope task: develop an offline **exact SDL/OpenGL raster oracle** for segmented rotated linear-sampled quads, including top-left edge coverage and float32 UV interpolation against the recovered emitted arrays, then use it to identify a low-complexity maximal transparent rectangle/hole mask across multiple active camera/zoom/shake frames. Only if that proves a bounded exact-safe mesh should a separate isolated B proceed to production build and serial physical NVE7 A/B/A with full-frame pixels, GL calls, p50/p95/p99 and memory proxy. No 8K/high-Hz/60-FPS/sustained/thermal/release acceptance is inferred here.
