# Waterfall-top ParticleSpray ID49 GPU review — 2026-10-22

## Verdict

**Accept this bounded ID49 software admission for the Linux port.** The focused loader/draw test, unchanged forest leaf regression, Docker production build, and physical Xorg/OpenGL waterfall A/B all passed. The splash is demonstrably present in the active waterfall-top scene; the ID49-only diagnostic excludes authored sprays 50/51. This is **not** matched-original Windows visual parity or Jerome acceptance.

## Source and change

`WATERFALL_SPLASH_ID49_IMPLEMENTATION_AUDIT_2026-10-22.md` traces the original XML/source contract. `Game/XmlFiles/levels/waterfall_top.xml` authors ID49 at `(320.985352,3530.298340)`, ground-front depth, 100 `waterfall_splash.png` particles, update/draw bounds `1000×3000`, signed spawn spreads, upward direction, 14–35 speed, 1–1.5 s life, 250–450 size, loop, and .25/.25 fade parameters. The existing port particle loader/update/draw stream already implements these parameters. `port/game/LevelScene.cpp` now admits `(waterfall_top.xml,49)` in addition to the pre-existing `(forest_exploration_1.xml,47)`, retains the actual XML ID/order/depth, and gives ID49 its own deterministic private RNG seed. It does not admit waterfall IDs50/51, change the forest seed, draw a giant emitter rectangle, or add a waterfall renderer special case. The RNG seed is for repeatable Linux captures, not Windows global-`rand()` parity.

At the port's 1280×720 logical output, the normal world-to-screen transform is 2/3; XML size/speed remain authored world values in the existing ParticleSpray path. The original's `Game::mGameScale` is 1280/1920 at a 1280 backbuffer, but its full camera/particle transform was not established as a pixel-exact comparator here. No extra per-emitter scale was guessed.

## Limits

The original global RNG's seed/call order (including the source's discarded spread draw), particle-by-particle age/spawn state, source camera cull/parallax details, independent D3D sampler/blend rounding, and original Windows game-scale/camera transform are not matched. The port still uses per-particle viewport culling in Draw instead of a source-style emitter draw gate; this test confirms offscreen absence and the expected active view, not every camera-boundary transition. Only one fixed gameplay frame was captured; temporal smoothness, all loop transitions, and Windows pixel parity remain unverified. Diagnostic `only49` still includes normal HUD/postprocess behavior, so its full-frame nonblack pixels are not counted as splash coverage. No user visual acceptance is claimed. Shared coordinator/status files were not edited.
