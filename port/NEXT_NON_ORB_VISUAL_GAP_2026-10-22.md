## Source attribution and limits

- Forest XML `Game/XmlFiles/levels/forest_exploration_1.xml:1631-1662` authors two large `kGroundFront` `ScrollingSprite` fog quads, IDs 119/122, both `Media/fog.png` with `effectpixelwobble`, intensity **0.07**, speed **0.30**, original alpha **0.5/0.6**, and **6 s fade-in** (45/70 s horizontal lerps). The original `ScrollingSprite::Update` uses `mOriginalAlpha * (mCurrentLerpTime / mFadeInTime)` before full opacity (`Game/src/GameObjects/ScrollingSprite.cpp:23-58`). `Sprite::Draw_effectPixelWobble` passes that float alpha (`Game/src/GameObjects/Sprite.cpp:675-688`); `Game/ShaderFiles/BasicLightTexture_PixelWobble.fx:56-64` offsets UVs with sine and multiplies sampled texture alpha. Thus early versus mature fog can plausibly yield the observed change without changing art or global color.
- Current port parses the effect (`port/game/LevelScene.cpp:507-510`), advances the authored scrolling fade (`:830-855`), passes float opacity and shader time at draw (`:1084-1099`), and uploads opacity to its wobble program (`port/linux/SDLRenderer.cpp:319-352,601-608`). This inspection finds **no missing fog draw or obvious alpha-formula omission**. The prior controlled, same-frame hide-ID study `port/FOREST_HAZE_GPU_DISCRIMINATOR_2026-10-22.md` found IDs 119/122 brighten a broad lower ROI and substantially more at frame 360 than frame 120. It is Linux layer attribution, not a Windows match. The former float-alpha rounding gap has already been fixed; `port/FOG_FLOAT_ALPHA_CONTROLLED_COMPARISON_2026-10-22.md` bounds its old frame-300 effect to at most one RGB code value in the fog region, far too small to explain this broad contrast.
- Dark lower shrubbery ID37 is a separate contributor, not a missing fog sprite: the controlled hide-ID study confines its frame-120 change to y>=597 while the fog contribution starts around y=246. The flat-topped pale right shaft in later clip views is attributed to ID15, which is outside screenshot 14's field (`port/FOREST_ID15_MATCHED_REFERENCE_2026-10-22.md`). Neither should be retuned to make this unmatched JPEG look closer.
