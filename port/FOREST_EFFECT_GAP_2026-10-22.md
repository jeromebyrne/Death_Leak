# Forest-1 per-sprite effect gap (read-only source audit, 2026-10-22)

## One concrete mismatch: scrolling fog alpha is quantized before its pixel shader

`forest_exploration_1.xml` assigns `effectpixelwobble` to foreground fog ScrollingSprite IDs 119 and 122, both on `kGroundFront`, with `Media\\fog.png`, intensity `0.07`, speed modifier `0.30`, and authored alpha `0.50` / `0.60` respectively (`Game/XmlFiles/levels/forest_exploration_1.xml:1625-1661`). Each also has a six-second fade at both ends (`:1645`, `:1661`). This is a per-sprite texture effect, not a full-screen fog pass: original `Sprite::Draw` dispatches `EFFECT_PIXEL_WOBBLE` to `Draw_effectPixelWobble` (`Game/src/GameObjects/Sprite.cpp:374-400`), which passes `m_alpha` directly to the effect (`:675-688`). Original `ScrollingSprite::Update` computes fade alpha in float (`Game/src/GameObjects/ScrollingSprite.cpp:47-57`); the HLSL samples the fog texture and multiplies sampled alpha by that float (`Game/ShaderFiles/BasicLightTexture_PixelWobble.fx:56-64`). Ordinary light-texture and foliage effects likewise multiply sampled alpha by a shader float (`Game/ShaderFiles/BasicLightTexture.fx:53-59`, `Game/ShaderFiles/FoliageSway.fx:61-67`).

The Linux scene retains the fade in `sprite.alpha`, but immediately rounds it to an 8-bit `sprite.tint.a` on load and every scrolling update (`port/game/LevelScene.cpp:487-489,688-694`). The draw copy passes the tint, not the float alpha (`:883`), and the custom fog GL path uploads `sprite.tint.a / 255.f` as `spriteAlpha` (`port/linux/SDLRenderer.cpp:267-270`); its fragment shader multiplies sampled alpha by that quantized value (`:485-497`). Therefore a source fade value such as 0.25 can become 64/255 ≈ 0.25098 before compositing. This is a real per-fragment opacity-input mismatch of up to 0.5/255, potentially a one-code-value final pixel difference at fog edges or overlaps. It is not a claim of a measured screenshot delta; no GPU capture was made in this audit. RGB and the sine-offset equations are not the finding.

## Minimal correction proposal

Keep `SceneSprite::alpha` as the float-of-record and add a float opacity field to `render::Sprite` for custom shader draws. Set it from `object.alpha` in `LevelScene::Draw`, and upload that float instead of `tint.a / 255.f` in `SDLRenderer::DrawPixelWobble`. Leave the existing byte tint for SDL copy/geometry paths; do not change UV/flip logic, effect timing, scrolling geometry, or global postprocess. A future implementation should compare a deterministic fade-frame fog-only pixel capture before/after and, if available, a matched Windows frame; this document establishes code-path divergence only.
