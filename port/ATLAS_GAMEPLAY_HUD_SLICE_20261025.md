# Opt-in gameplay HUD atlas: bounded second family (2026-10-25)

Scope: six `Hud::Load` textures in `port/game/Hud.cpp` (health/focus meter bars, caps, overlay and orb count). These are ordinary `DrawSprite` copies after scene postprocess, with tint, horizontal/vertical flips and variable destination widths; no authored repeat-X, UV shift or private shader call in `Hud::Draw`. Other `Game/Media/UI` paths are not admitted by the exact region lookup. Scene XML repeat/parallax, PixelWobble/foliage/damage private GL, wrap, render targets and source-rect variants remain outside this family; if a virtual ID is ever sent through repeat/shift/private-shader branches, `DrawSprite` lazily loads its dedicated original PNG and uses the original rendering path. Ordinary source crops retain virtual source dimensions and region offset.

Generated `port/assets/gameplay_hud/`: one trimmed **234×132** RGBA page, 2-pixel extrusion, six source hashes and rectangles in the manifest/lookup. All six reconstructed RGBA crops byte-match their PNG sources; a second generation was byte-identical for PNG, manifest and TSV. The page is 123,552 RGBA bytes versus a 4096² page's 67,108,864 bytes; only one page is resident when the opt-in `DEATHLEAK_ATLAS_HUD=on` is used. The six source image areas sum 26,008 pixels of 30,888 page pixels (~84.2% content-area occupancy, before extrusion).

Build: isolated `port/build/atlas-hud-slice/deathleak-linux`, with staged-clean renderer source overlaid; pre-existing unstaged raft-mip renderer edits excluded. Physical Xorg `:0`, nouveau NVE7, SDL x11/OpenGL accelerated=1/software=0/vsync=1, 1280×720.
