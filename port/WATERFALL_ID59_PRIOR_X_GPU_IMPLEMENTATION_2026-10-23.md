# Waterfall ID59 prior-update X implementation and GPU A/B — 2026-10-23

## Scoped implementation

Implemented only the waterfall-top ID59 followed-X world placement in `game/LevelScene.h/.cpp`. Each new sprite initializes `followWorldX` from authored X (2778.985352 for ID59). On each nonpaused, eligible ID59 object update, it captures the existing position into `followWorldX`, then stores current camera X into `sprite.x`. Draw uses cached world X for ID59 destination only; current camera X still drives view subtraction and UV. No renderer, XML, assets, Y path, other followed layer, or shared checkpoint was edited. This follows the checked-in Windows `GameObject::Update` world-matrix-before-`ParallaxLayer::Update` follow assignment; it does not prove shipped-binary parity.
