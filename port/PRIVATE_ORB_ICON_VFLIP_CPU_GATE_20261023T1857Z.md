# Private orb-icon vertical orientation CPU gate — 2026-10-23 18:57 UTC

## Decision

**No vertical-orientation mismatch is established. Do not set `flipY=true` on the orb icon.** The XML's `vflip=true` must be interpreted with the original UI's **Y-up** quad: `UISprite::RebuildBuffers` assigns V=0 to its geometrically top vertices and V=1 to its bottom vertices. With a conventional D3D PNG texture (V=0 at the PNG top), the original on-screen top samples the PNG top. Linux `Hud` emits `flipY=false`, and the ordinary SDL copy likewise places the PNG top at the screen top. A blind `flipY=true` edit would introduce the opposite orientation. This is a source/CPU conclusion, not a matched-Windows pixel acceptance.

A separate, small **placement** difference is source-proven: at 1280×720, XML `posY=360` is the *bottom-left* Y-up coordinate, and `height=64`; the original projected top is `(540-(360+64))*2/3 = 77.3333`, while the Linux HUD command uses top Y=80. Its bottom is 122.7 versus source 120. The next non-overlapping correction, if an owner chooses this bounded slice, is confined to `port/game/Hud.cpp`: set orb destination to `{40, 77.3333f, 67.3333f, 42.6667f}` (or the equivalent exact scale expressions), leave `flipY=false`, and verify the HUD command without editing `SDLRenderer.cpp`. That is distinct from the Impact font gate and the separately owned focus-meter UV fix. No production source was changed in this lane.

The UI image is loaded with `D3DX10CreateShaderResourceViewFromFile` (`Game/src/Core/TextureManager.cpp:82-98`).

In current `port/linux/SDLRenderer.cpp:205-280`, the ordinary no-rotation/no-flip icon takes `SDL_RenderCopyF` with whole texture and no UV shift, repeat, or private GL path. SDL's normal PNG copy maps top image row to top destination row. The later custom GL UV code is in other branches and does not execute for this icon.
- Isolated C++ CPU renderer spy compiled `port/game/Hud.cpp` against a renderer stub (no SDL/GPU/Xorg): first sprite was `Game/Media/UI/orb_count.png` with `{x=40,y=80,w=67.3,h=42.7}`, alpha `191`, `flipX=0`, `flipY=0`; nine total sprites. - The actual `Game/Media/UI/orb_count.png` is 202×128, SHA-256 `63516679e03c2b2d453b9b2f83170feaa79798485e5ae13b9cabf34349892844`, and is vertically asymmetric: Pillow RGBA alpha sums at rows 0/64/119/127 are `86/29365/0/0`.
