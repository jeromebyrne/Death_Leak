- The two XML object inventories contain 42 ordinary `Sprite`s, 22 `CurrencyOrb`s, three `ParallaxLayer`s, two `ScrollingSprite`s, one `ParticleSpray`, and one `Player` in forest-1; waterfall-top has 43, 22, 10, four, three, and one respectively. Thus ID4 cannot explain a broad missing visible layer. The port separately admits its collision box (`port/game/LevelScene.cpp:261-270`). This count is a static XML inventory, not a runtime visibility assertion.
- The Windows normal texture path multiplies sampled RGBA by `lightColor` and alpha by the object's alpha (`Game/ShaderFiles/BasicLightTexture.fx:8-18,52-59`). Its ordinary `Sprite` draw resets `lightColor` to white after each draw; the nonwhite branch is the timed burst tint (`Game/src/GameObjects/Sprite.cpp:627-673`). The port already supplies per-object tint/opacity and player burst gain in the depth-ordered scene draw (`port/game/LevelScene.cpp:930-1033`). The burst has its own implementation and rotation audits (`port/DAMAGE_BURST_VISUAL_FIX_2026-10-22.md`, `port/DAMAGE_BURST_ROTATION_CONTRACT_AUDIT_2026-10-22.md`); a global light-color correction would not be justified.
- Normal source drawing is alpha-gated and view-gated in painter order (`Game/src/GameObjects/GameObjectManager.cpp:302-330`). The port's current draw interleaves dynamic sprites and sprays by depth, retains authored object order, supplies source-equivalent depth-dependent screen parallax, UV phase, alpha and sprite effect state (`port/game/LevelScene.cpp:930-1033`). The remaining follow-camera previous-position matrix question is already specifically isolated for forest IDs 37/40 in `port/NEXT_POST_ROTATION_VISUAL_GAP_2026-10-22.md` and `port/PARALLAX_FOLLOW_TEMPORAL_TRACE_2026-10-22.md`; it is transient and not evidence for a new persistent dark-band defect.
- The broad waterfall sheets, fog and splash cases are covered by the existing autoscroll/wobble, rotation/cull, surface-blend and particle audits (`port/NEXT_VISUAL_SOURCE_AUDIT_5_2026-10-22.md`, `port/NEXT_WATERFALL_VISUAL_DISCRIMINATOR_2026-10-22.md`). The current scene loader explicitly admits forest leaf ID47 and waterfall splash IDs49–51 (`port/game/LevelScene.cpp:271-324`), so they are not a newly missing class. Currency-orb animation and waterfall small-orb hover/tracking have dedicated current port paths (`port/game/LevelScene.cpp:425-471,688-731`) and prior audits. None of those observations establishes a *new* high-coverage error.
