## Verdict and limits

The post-commit physical GPU frame renders visible source-shaped rain. The render-only A/B attributes the visible streaks to the port rain draw rather than the underlying forest, and no narrow source-backed rain rendering defect was identified in this frame. No software fix was made or pushed. This is **not** matched Windows pixel parity or human visual acceptance: the port uses a private deterministic RNG instead of the original process-global Windows `rand()` stream, and the generic sprite path only approximates original D3D `Particle.fx` sampling/blending. The frame has no proven lightning flash, so same-depth lightning/rain overlap remains unverified. Rain/thunder audio and weather intro/outro sound behavior are outside this visual slice.
