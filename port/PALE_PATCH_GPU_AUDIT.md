# Right-side pale patch physical-GPU attribution — 2026-10-22

## Verdict

The conspicuous near-horizontal pale rectangle at screen right in the post-foliage forest-1 footage is **XML sprite ID 15**, an authored `Media/sun_shaft_2.png` light shaft, not the moving fog IDs 119/122. A deterministic 540-frame physical-GPU capture reproduces the post-foliage 9-second composition. Hiding only ID 15 removes the distinctive right-side slab while leaving the forest, player, other haze, and game state in place; rendering only ID 15 displays that same flat-topped rectangle at the same position. The source PNG itself is a 512×512 yellow, mostly rectangular alpha field with a short transparent margin and a fairly straight edge. Source XML explicitly places it there at full object alpha with ordinary light-texture sampling. **No source-backed renderer correction is indicated by this attribution.** Do not hide ID 15, remove its XML entry, or retouch its authored texture as a release fix on this evidence.

## Original-Windows source/render-pass attribution

- `Game/XmlFiles/levels/forest_exploration_1.xml:237-251` authors ID15 as a `Sprite` at `(2796.985,3207)`, 512×512 native size, `kGroundFront`, rotation `-1.47`, alpha `1.0`, `effectlighttexture`, `Media/sun_shaft_2.png`, no vertical flip or occlusion fade. It is **not** a `ScrollingSprite`, fog layer, blank-white overlay, or foliage/wobble effect. ID14 uses the same image elsewhere in the level and is invisible in this frame.
- `Game/Media/sun_shaft_2.png` is RGBA 512×512. Direct asset inspection: at central source column x=256, source alpha is 0 at rows 0–70, 9 at y100, 53 at y200, 97 at y300, 140 at y400, 162 at y450, 82 at y480, 21 at y490, then 0 by y500. It is a broad, almost constant-width yellow field with narrow/short edge feathering, so a straight-looking edge is in the authored texture itself. Original `Sprite::RecalculateVertices` (`Game/src/GameObjects/Sprite.cpp:194-235`) maps the texture across one quad; `Sprite::Draw_effectLightTexture` (`:626-672`) passes the current alpha; `Game/ShaderFiles/BasicLightTexture.fx:53-59` samples RGBA and multiplies sample alpha by object alpha. The original blend state uses source-alpha-over (`Game/src/Core/Graphics.cpp:392-407`), followed by the scene Sepia.fx pass. No original source path intrinsically blurs or procedurally softens this shaft's rectangular geometry.
- The Linux scene parses ID15's dimensions, position, rotation, depth, effect-independent alpha and authored flips (`port/game/LevelScene.cpp:350-465`) and sends it through the ordinary sprite path (`:728-785`; `port/linux/SDLRenderer.cpp:169-235`), not the pixel-wobble GPU path. Its `kGroundFront` placement means nearer trunks/objects can mask parts of the rectangle, explaining why the visible boundary begins around x985 and extends off the right viewport. The white overlays IDs 38/39 and later sepia alter perceived brightness but are not its geometric origin.
