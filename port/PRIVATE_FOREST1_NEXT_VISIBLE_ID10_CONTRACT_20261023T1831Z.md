## Exact original Windows contract versus Linux

Original Forest-1 XML (`Game/XmlFiles/levels/forest_exploration_1.xml:33-46,176-190`) authors player ID2 at depth `kPlayer` (3000), opaque, and ID10 `tree2_blur.png` at `kMiddleForeground` (1000), alpha 0.7, horizontally flipped, `fade_when_player_occluded=false`. The unused conditional fade targets on that ID are 0.5/1.0; the false flag is decisive. `Game/src/GameObjects/DrawableObject.cpp:41-55` enters its player-rectangle/1.5*dt fade logic only when the flag is true. `Game/src/GameObjects/GameObjectManager.cpp:1021-1025,302-330` depth-sorts/traverses drawables, so ID10 paints after ID2. `Game/src/GameObjects/Sprite.cpp:626-637` supplies ID10 alpha to `BasicLightTexture.fx:53-59`, which multiplies the sampled texture alpha once. Its sampler requests `MIN_LINEAR_MAG_POINT_MIP_LINEAR` and WRAP (`BasicLightTexture.fx:10-16`). Thus dark blurred foreground covering some player pixels is an authored output, not an automatic occlusion-fade failure.

Current port `port/game/LevelScene.cpp:624,1335-1350,1385-1388` stably depth-sorts/traverses the same sprite list, gives the ID10 draw its authored alpha, and draws it after the player; `:918-942` also gates fade on the authored flag. `port/linux/SDLRenderer.cpp:220-234` applies the ordinary texture tint alpha and chooses nearest for a magnified copy. ID10's PNG is 669x1650 (`file Game/Media/objects/tree2_blur.png`); its XML 1686.031x4158.374 world quad projects at ordinary 2/3 scale to about 1124x2772 screen pixels before clipping, so the ordinary scene copy is magnified on both axes and the selected point mode matches the original magnification filter. SDL's single scale-mode API is a general implementation difference from D3D's separate min/mag/mip sampler, but no ID10-specific filter divergence at this magnified clip pose is demonstrated. Exact mip/edge pixels would still require a matched frame/state.

An earlier fixed-frame Linux-only ID2/ID10 hide experiment at frame 540 measured 2,735 player-mask pixels and median player contribution 11.996 luma codes with ID10 versus 38.694 without (`FOREST_PLAYER_CONTRAST_9S_GPU_GATE_2026-10-23.md`). That causally establishes ID10 attenuation in **that older frozen capture**, not a numerical measurement in this current-HEAD 9-second still, and not Windows parity. No extrapolation of its mask/count to this clip is made.
