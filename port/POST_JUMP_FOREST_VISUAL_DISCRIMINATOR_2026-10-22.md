# Post-jump forest visual discriminator — lower bridge atmosphere (2026-10-22)

## Decision

The highest-impact **apparent non-jump** difference between the identified current 10-second active forest-1 clip and the available original Steam reference is the **broad lower bridge/ground atmosphere** near the clip's early bridge view: the Linux scene presents darker, crisper underlying ground and raft edges, whereas Steam screenshot 14 presents a brighter, softer-looking veil across that region. This is an *image-level, qualitative observation*, **not an established Windows-versus-Linux renderer defect**. It occupies much more of the scene than the localized running-footstep spray, the already-ported small-orb trail, or the source-proven but measured-low-contrast ID37 follow-position lag. No jump-takeoff effect is considered here or assigned for implementation.

## Source-backed explanation to discriminate, not yet a defect

`Game/XmlFiles/levels/forest_exploration_1.xml:1625-1665` authors IDs 119/122 as large `Media/fog.png` `kGroundFront` scrolling sprites with alphas 0.5/0.6, six-second fade-ins, and pixel-wobble effect; ID122 is vertically flipped. Windows `Game/src/GameObjects/ScrollingSprite.cpp:22-55` ramps each opacity as original alpha × elapsed/6 before full opacity. Current Linux `port/game/LevelScene.cpp:871-893` implements the corresponding clock, scroll and fade rule. Consequently an early Linux bridge view can expose sharper/darker underlying edges while an original screenshot taken later in the fade could show a larger veil, with **no fix required**. The near-black bottom strip is separately authored ID37 `shrubbery.png` at alpha .95 (`forest_exploration_1.xml:612-635`); isolated GPU evidence confines its effect to y≥597, so neither hiding nor brightening it is an evidence-backed response to the broader veil. `FOREST_BRIDGE_ATMOSPHERE_SOURCE_AUDIT_2026-10-22.md` and `LOWER_FOREGROUND_PARITY_2026-10-22.md` also found no established fog/ID37/global blur defect from the unmatched images.

On an exclusively scheduled GPU lane, reproduce that state in one identified Linux frame. Register static pickup/branch/raft landmarks first; preserve the Steam image's aspect ratio if using it only as a composition guide. Compare a fixed lower-ground ROI after registration and, only if a material residual remains, isolate 119/122 and ID37 in **same-state** render controls to locate it. Acceptance criterion for a source change: a repeatable matched-state residual attributable to a specific fog transform, opacity, UV/wobble, blend or painter-order operation. If none remains, close the apparent difference as state/reference presentation; do not retune art, alpha, fade, ID37, sepia or global sharpness merely to fit Steam 14. No source implementation is authorized by the present unmatched evidence.
