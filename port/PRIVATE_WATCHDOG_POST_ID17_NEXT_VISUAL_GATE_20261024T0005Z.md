Sample an interior, non-transparent asset row and quantify source-coordinate/premultiplied-alpha differences at several horizontal fractions; include zero-rotation and non-repeat controls. This is a source-contract oracle, not a Windows comparison.

After the exclusive ID17 owner releases renderer/build/GPU, a foliage-path owner can instrument a **private** ID67-only draw-state trace or A/B at the same first-active state, choosing a visible mid-strip ROI away from player/HUD and later opaque occluders. Capture lossless pre-/post-ID67 or ID67-only layers and an unaffected control crop. If ROI sensitivity is material, implement only the rotated foliage-sway UV span/phase in that path, preserving vertex intensities, rotation, authored alpha and painter order. A source-built, state-matched original D3D10 packet would still be required to call any result Windows pixel parity; do not assume one exists. If isolation shows complete occlusion or negligible effect, close this candidate without a renderer patch and choose a different visible owner.
