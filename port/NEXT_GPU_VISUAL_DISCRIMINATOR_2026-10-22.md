# Next GPU visual discriminator — player knife lifecycle (2026-10-22)

## Outcome and priority

At HEAD `a4bfb61`, the highest-priority *demonstrated* remaining mismatch in the 10-second held-fire forest route is the player knife's appearance and premature removal. Each port knife is drawn immediately at full alpha and full 84.5 × 25 world-unit size, then removed after 0.25 s even without contact. The Windows source starts it transparent, grows both alpha and dimensions for 0.3 s, and uses the authored 0.25 s as a **post-impact inactive retirement** interval, not an active-flight lifetime. Thus a port knife cannot even reach the source's full-visibility age. This is a definite source/port code differential and a repeatable focal gameplay visual; it is not a measured pixel-parity claim. The incorrect lifetime comment in `port/game/Combat.cpp:219-223` is itself a clear code defect.

This outranks conditional lightning (first weather after 180 s) for the reviewed 10-second route, and avoids ungrounded changes to the authored dark ID37 foreground or ID15 right shaft. `port/RIGHT_SHAFT_PARITY_2026-10-22.md` concluded no ID15 fix. The concurrent read-only UV QA lane was not touched or duplicated.

## Next bounded fix and proof gate

For **player knives only**, track active visual age separately from collision/retirement state. At spawn use zero alpha and dimensions; after each active update render `t = clamp(activeAge / 0.3f, 0, 1)` for alpha and both visual dimensions, retaining the existing knife texture, centered position, and horizontal flip. Remove the erroneous 0.25-second active countdown: preserve current contact handling and, if retaining an embedded/impact visual, start the 0.25-second retirement timer **at contact** as the source does. Add a conservative offscreen retirement bound if needed to keep the port's simplified combat collection finite; that bound must not masquerade as the authored 0.25 s. Do not modify art/XML, scene-wide blending, ID15/ID37, or NPC projectile behavior in this patch.

A useful narrow deterministic proof is the same camera/player/fire input at shot ages 0, 0.15, 0.30, and 0.35 s with and without the fix (or an isolated knife crop on the physical GPU): the first frame should be transparent, the 0.15 s knife half-size/half-alpha, and an unimpeded 0.30 s knife full-size/full-alpha and still alive. Also verify contact still removes or retires it correctly and replay the established 10-second held-fire route. This A/B proves the port correction against the source formula; exact Windows pixel parity still requires matched camera, projectile state, viewport, and frame timing.
