# Presentation/matte source gate — 2026-10-23 22:44Z

## Verdict

**Source does not attribute Steam screenshot 16's 32/33-row black matte.** The checked-in original D3D10 path requests a 1920×1080 backbuffer and a coincident full-buffer viewport, clears both render targets black, draws a nominally full-buffer postprocess quad, draws UI afterward, then Presents. No explicit gameplay letterbox/resize path was found in the bounded original game-source call-site search. Thus a fixed 32/33-row matte is **not specified by this source path**. It is still possible for black edge pixels to reside inside a native backbuffer (e.g. particular scene/overlay/shader output or unverified runtime behavior), or to be introduced by DXGI/desktop/Steam/store capture processing. Source alone cannot choose among those. Do not add bars or change Linux viewport.
