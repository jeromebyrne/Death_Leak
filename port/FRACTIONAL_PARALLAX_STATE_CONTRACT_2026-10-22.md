## New actionable state finding

`DrawPixelWobble` is the closer interop template (`SDLRenderer.cpp:335-405`): unlike `DrawDamageBurst` (`:270-333`), it captures **unit-0 `GL_TEXTURE_BINDING_2D` before SDL binding** and restores it after `SDL_GL_UnbindTexture`. The latter path does not explicitly restore that binding. Do not copy its early-return cleanup into fractional parallax. `glPushAttrib(GL_ALL_ATTRIB_BITS)` restores context attributes, **not mutations of the SDL texture object's sampler parameters**; wrapping and filters must be read from the bound object and restored while it is still bound. A direct fixed-function quad also needs an explicit fragment modulation contract: `SDL_SetTextureColorMod`/`AlphaMod` at `:215-216` configure SDL copies but do not establish immediate-mode GL color/texture-env state. `Sprite::opacity` remains a separate float (`Renderer.h:45-51`, `LevelScene.cpp:1246-1247`).

Implement one balanced transaction inside the existing UV-scroll branch, after its higher-priority effects/repeat-X: flush SDL; verify desktop-`opengl` and finite shifts; save current program, matrix mode, active unit and GL attributes; select unit 0 and save its 2D binding **before** `SDL_GL_BindTexture`. On bind failure, restore without unbinding and take the original SDL integer-copy fallback. On success, measure both returned spans and NPOT capability; if ineligible, unbind, restore the old binding/attributes/active unit/program/matrix mode, then fall back exactly once. If eligible, snapshot bound-object wrap S/T and min/mag; use repeat S/T and complete base-level linear-min/nearest-mag sampling, and draw the TL/TR/BR/BL helper UVs unchanged. For a fixed-function draw, explicitly use program 0, `GL_MODULATE`, white-relative `glColor4f(tint.rgb/255, tint.a/255 * opacity)`, source-over blend and existing logical projection/SDL viewport+scissor. Alternatively use a dedicated shader with identical sampled RGBA multiplication; do not rely on inherited program, current color, or texture environment. Restore projection/modelview stacks, original matrix mode/program, **all four object sampler parameters before unbind**, original unit-0 binding, attributes and original active unit on success and every failure exit. Do not mutate SDL-owned mip/base/max levels or PixelWobble's private mip cache. The next ordinary SDL copy is the state-leak sentinel.
