# Same-alpha mixed-command GPU replay gate — 2026-10-26

**Decision: reject visible runtime B.** The diagnostic comparator and production build pass, but fractional-alpha current/mixed composition is not yet coherent: stable background/painter sprites advance while unowned active-game world effects and the player remain at the current tick. No runtime interpolation is enabled, and no A/B/A performance claim is made.

## Exact source and comparator

Base `adf520b3cdea90927f0c6d66840c400ceca83227` was verified equal to `origin/feature/linux-renderer-foundation` before work. Changes were built in detached `/tmp/deathleak-same-alpha-replay-20261026`, not the primary dirty checkout. The opt-in diagnostic flags `--mixed-replay-prefix PREFIX --mixed-replay-frame N` imply packet recording and require a rendered frame N in `[1,frames-1]`. At N, after ordinary presentation, three complete sealed packets are replayed serially: current, mixed alpha=1, mixed alpha=.5. Each packet executes its own Begin/Zoom, original painter commands, postprocess/resolve through the same renderer, RGBA scene target, SDL/OpenGL shader, sampler and blend path. Captures are read from the unswapped output backbuffer; replay arms are **not presented** and the next ordinary BeginFrame replaces the diagnostic backbuffer. The comparator does not fabricate an alternate game update or drop animated/film/HUD commands. It is a same-renderer same-target/state-path comparison, not an independent OS-window or driver-state snapshot. There is no visible B switch.
