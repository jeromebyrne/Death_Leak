## Decision and next mechanism

**Reject single-orb shared-page runtime routing.** Strict exact-pixel gate fails at two camera phases; the ten-frame page is ineligible even though packing and source bytes are exact. Default atlas coverage remains **15/896**; no accepted submission/bind/timing/VRAM improvement. No serial performance benchmark was run on an already rejected pixel arm. Next distinct, technically safer precision gate: make a matched physical *dedicated-versus-atlas* source-local sampler probe where both arms use the **same quad geometry, GL shader, tint/blend and postprocess**, changing only source texture/rectangle; first compare hardware linear and four-center nearest fetches on the dedicated image itself, then test the page. The earlier cart-only private shader changed geometry/state and 11,157 pixels, so it cannot be reused as orb evidence. Until such a probe is exact on physical NVE7, retain these minified/flipped orb frames dedicated. Ordinary point-sampled families may be independently eligible, but none is claimed here without its own source and A/B/A gate.
