# Combat painter-order checkpoint — 2026-10-22

## Correction

The Linux port now interleaves scene sprites/sprays with runtime combat and pickups in one descending source-depth stream. `Combat::AppendPainterItems` emits NPCs at 3500, ghost/skeleton projectiles at 2530, ninja stars at 2510, and player knives at 2500. Projectile depth is retained after deflection, matching the source object's fixed depth. `LevelScene::Draw` stably merges those entries with authored XML sprites/sprays and spawned currency orbs at 3250. The runtime health-upgrade pickup now participates at its inherited `kPlayer`/3000 depth, instead of painting after all foreground. Equal-depth authored objects remain ahead of later runtime objects. Foreground at 1750/1500/1000/500 therefore paints after (and can alpha-occlude) knives, NPCs, or pickups at an overlap; player, shadows, backgrounds and HUD retain their established paths. No source art/XML changed.

Source basis: `Game/src/GameObjects/GameObject.h` depth enum, `Game/src/GameObjects/GameObjectManager.cpp` stable descending sort/draw, `Game/src/GameObjects/Player.cpp` player projectile constructor, `Game/src/GameObjects/NPC.cpp`, `GhostEnemy.cpp`, `SkeletonEnemy.cpp` projectile constructors, and `SolidMovingSprite.h` default `kPlayer` pickup depth. The `kBombProjectile` layer exists in Windows but the Linux combat slice does not implement that projectile; this change does not claim to add it.
