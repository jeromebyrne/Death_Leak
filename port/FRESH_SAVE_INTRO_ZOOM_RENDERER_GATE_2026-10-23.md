## Minimal renderer integration (handoff specification)

1. Have the caller compute one **effective, finite** per-frame zoom from its fresh-forest intro state; use it for both `FollowCameraWithTarget` and the scene world pass. Keep authored `CameraZoom()` outside that specific intro and restore exact load zoom at phase-2 entry. Define a narrow renderer API such as `SetWorldZoom(float)` (default 1, explicit reset) called **only after BeginFrame and before scene/painter drawing**. `ApplyScenePostprocess` must end world phase/reset zoom before film, bars, HUD, modal and death overlays. Alternatively a scoped BeginWorld/EndWorld pair is fine if it has the same boundary. Neither menu nor `--level-preview` should inherit it.
2. At zoom `z`, map every world-pass logical destination around viewport center: `x' = 640 + (x-640)/z`, `y' = 360 + (y-360)/z`, `w'=w/z`, `h'=h/z`. Apply to the *central renderer draw site* for ordinary sprites **and** its private GL/effect paths and world `FillRect`; use the transformed destination consistently for rotation centers, UV/wobble/foliage geometry, repeat-X tile generation/clipping and any fallback. Do not scale texture source rectangles, tint/opacity, UV shift, or pixel shader clocks. At `z=1`, keep the old route bit-identical. The zoom must not touch postprocess's fullscreen quad or UI, which are screen-aligned. A whole-frame zoom after sepia is wrong (zooms HUD); a scene-only framebuffer crop before sepia is a possible visual prototype but raster-resamples an already rendered scene and is not the exact original projection contract.
3. Preserve SDL's existing logical 1280x720 viewport and the scene/sepia framebuffer. Avoid relying on `SDL_RenderSetScale` without accounting for its logical-size/viewport state and private GL calls, which bypass SDL's transform. Clip/cull conservatively: a zoom-in sees *less* than the current scene, so existing broad scene submission remains safe; do not let the 1280-wide repeat-X helper stop short after transformation. Reject nonfinite/nonpositive zoom rather than generating nonfinite GL/SDL coordinates. No persistent zoom across scene transitions or failed/early postprocess.
4. No blanket edit to `main.cpp` by the renderer worker. Give this contract to the intro caller owner; they wire the one API call and source-derived effective zoom after their CPU state is stable. Do not introduce unrelated global sprint zoom or apply an active-gameplay zoom to continuation saves.
