## Verdict

**The strongest still-open, visibly consequential Forest-1 effect discrepancy outside ID2/ID10, ID37 and HUD film is raft light-texture minification.** This is a *source-predicted sampling gap and a proven Linux-local pixel sensitivity*, not a proven original-Windows pixel mismatch or a new implementation assignment. The ordinary Linux path draws Forest raft IDs 11/57/58 from one base-level SDL texture with linear minification. The original light-texture shader requests linear minification with mip-linear blending. The opt-in dirty GL experiment changes 36,665 post-sepia pixels in a fixed active Forest frame, so this is material enough to gate. Whether original Windows actually exposes multiple mips at the bound raft draw is unknown. Do not promote the experiment to the default path yet.

This candidate is already documented/owned by the raft-mip renderer and Windows-bound-view lanes (`NEXT_POST_ANIMATION_VISUAL_GAP_2026-10-23.md`, `FOREST_RAFT_MIP_SAME_STATE_GPU_DISCRIMINATOR_2026-10-23.md`, `RAFT_MIP_WINDOWS_BINDING_GATE_2026-10-23.md`). Prior broad inventories (`FOREST1_NEXT_UNOWNED_VISUAL_EFFECT_2026-10-23.md`, `FOREST_NEXT_VISIBLE_EFFECT_SOURCE_GATE_2026-10-23.md`) found no additional missing high-impact authored effect class.
