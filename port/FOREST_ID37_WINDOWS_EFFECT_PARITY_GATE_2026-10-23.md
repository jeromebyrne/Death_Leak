The current GL path uses REPEAT U/V, `GL_LINEAR` min and `GL_NEAREST` mag (`:418-427`); this approximates the source min/mag rules but has no mip-linear selection. With a 2048×512 image projected at 1365×341, mip behavior is a remaining edge/texture-detail uncertainty, not a demonstrated gross-band cause.
