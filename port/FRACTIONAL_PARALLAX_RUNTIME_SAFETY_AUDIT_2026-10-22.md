## Bounded renderer patch recommendation

1. First harden shared `port/linux/UVWrap.h:15-18`: after `pixels <= 0`, use phase zero when `!std::isfinite(shift)` **before** `floor` or conversion; leave finite cut/flip/segment behavior unchanged. This makes an invalid axis one full-source segment with offset zero, while a finite other axis scrolls normally. It is a deterministic neutral fallback, not invalid-input visual parity. Do not sanitize only the command or clamp after the conversion.
2. In `SDLRenderer.cpp:246-261`, form `ParallaxUVScrollInput` using existing destination, already signed `uvShiftX/Y`, flips, `!sourcePtr`, and zero rotation. Keep the current nested SDL-copy body as one fallback, entered exactly once whenever direct preparation/binding fails. For a non-`opengl` backend or nonfinite shift, skip GL entirely and use that hardened fallback. If a future refactor returns `NotApplicable`, take the ordinary path, never a direct quad. Also avoid issuing a direct GL quad for nonfinite/degenerate destination geometry; this seam does not validate destination, so add that renderer-level guard without claiming the legacy SDL path is globally safe for arbitrary invalid geometry.
3. For eligible candidates only, `SDL_RenderFlush`, save current program, matrix mode, active unit and GL attributes; activate unit 0 and save `GL_TEXTURE_BINDING_2D` **before** `SDL_GL_BindTexture`. Bind once, query returned spans and the bound level-0 width/height, compare actual allocation to logical SDL dimensions, and establish NPOT support. Prepare the command with this measured binding. On failed or ineligible bind, restore all captured state, unbind iff bind succeeded, then take fallback. `DrawPixelWobble` at `SDLRenderer.cpp:335-405` is the closer interop model; `DrawDamageBurst` at `:270-333` does not explicitly restore the previous unit-0 binding.
4. For `FloatQuad`, snapshot the SDL object's wrap S/T and min/mag parameters; set repeat S/T, `GL_LINEAR` min and `GL_NEAREST` mag (base-level-complete first slice; do not alter mip/base/max levels or the private wobble texture). Pair destination TL/TR/BR/BL with `command.uv[0..3]`. Establish deterministic program 0/fixed-function texture modulation or a dedicated trivial sampler shader; apply tint RGB and `tint.a/255 * sprite.opacity` once, source-over blend, disabled depth, logical 1280×720 projection, and retained SDL viewport/scissor. `SDL_SetTextureColorMod/AlphaMod` at `:209-210` does not set the immediate-mode GL color; `Sprite::opacity` is separate at `port/render/Renderer.h:45-51`. Check existing SDL fallback's alpha convention before claiming exact alpha parity.
5. One cleanup route for all post-snapshot exits: pop pushed matrices; restore program/matrix mode; restore all four sampler parameters **while that SDL texture is bound** (attribute pop cannot undo object mutations); unbind iff bound; restore old unit-0 binding, attributes and active unit. Verify the next ordinary SDL copy has unchanged appearance/state. No global texture parameter changes should survive the transaction.
