# Fractional parallax: SDL bind-span runtime gate (2026-10-22)

Read-only CPU/source finding; no renderer edit, build, SDL run, or GPU claim. This narrows the existing binding patch spec to the measurement that must happen **on the selected live SDL OpenGL renderer** for forest IDs 37/40.

## Exact gate to wire in the existing UV-scroll arm

`port/linux/SDLRenderer.cpp:246-261` still floors scroll to integer source cuts and does not call `ParallaxUVCommand.h`. IDs 37/40 use 2048×512 `shrubbery.png` and 2048×677 `trees_top.png` (forest XML `:612-689`); those are **logical image sizes, not evidence of the SDL-bound GL allocation or returned UV span**. The helper (`ParallaxUV.h:25-38`) requires both measured spans within 1e-6 of 1 and full NPOT repeat support when the **bound allocation** is NPOT.

In that arm only, after `SDL_QueryTexture(texture, ..., &logicalW, &logicalH)` succeeds with positive dimensions, finite shifts, and an `opengl` SDL renderer plus non-null `SDL_GL_GetCurrentContext()`:

1. `SDL_RenderFlush(renderer_)`; snapshot GL state, select `GL_TEXTURE0`, then call `SDL_GL_BindTexture(texture, &spanX, &spanY)` **once**. Preserve the success/failure result. Its output floats are the authoritative usable SDL UV spans; neither PNG dimensions nor `SDL_QueryTexture` can replace them. Failure, nonfinite/zero/nonunit span, or non-OpenGL driver selects unchanged integer copies.
2. While successful binding remains active, verify a nonzero `GL_TEXTURE_BINDING_2D` and query **that object** with `glGetTexLevelParameteriv(GL_TEXTURE_2D, 0, GL_TEXTURE_WIDTH, &allocW)` and `GL_TEXTURE_HEIGHT` for `allocH`; require no query error and positive dimensions. Log logicalW/H, allocW/H, spanX/Y, GL version/capability and chosen path by texture ID. Do not infer allocation from a 2048×677 PNG or round `logical/alloc` into a presumed span. If allocation query is unavailable/invalid, fall back. Determine NPOT from `allocW/allocH` using positive power-of-two checks.
3. On desktop GL, full NPOT `GL_REPEAT` is core at version **2.0+**, or requires an explicitly verified `GL_ARB_texture_non_power_of_two` extension below 2.0. Read capability from this current context (`glGetString(GL_VERSION)` / exact extension token, with the version-appropriate extension query); unknown, malformed or GLES context means unsupported. `GL_APPLE_texture_2D_limited_npot` or `GL_OES_texture_npot` should not be silently treated as this desktop full-repeat proof. Pass these actual facts into `ParallaxUVBinding`, then `PrepareParallaxUVCommand`; a `LegacyInteger` command keeps the original nested `ForEachUVWrapSegment`/`SDL_RenderCopyExF` fallback exactly once. A subunit Y span for ID40 is a fallback, never a padded-allocation repeat using scaled UVs.

## SDL/GL state boundary

`DrawPixelWobble` (`SDLRenderer.cpp:334-405`) is the closest interop model, not proof that this new path is safe. Snapshot `GL_CURRENT_PROGRAM`, `GL_MATRIX_MODE`, `GL_ACTIVE_TEXTURE`, unit-0 `GL_TEXTURE_BINDING_2D` and attrib state **after the flush**; restore on every bind-failure, ineligible, and draw exit. If direct drawing mutates the SDL-owned texture, read and explicitly restore `GL_TEXTURE_WRAP_S/T` and `GL_TEXTURE_MIN_FILTER/MAG_FILTER` **while it is still bound**; `glPopAttrib` does not undo texture-object sampler edits. Use `GL_REPEAT`, `GL_LINEAR` min (no mip requirement), `GL_NEAREST` mag only for an eligible quad. Call `SDL_GL_UnbindTexture` only after a successful bind, then restore previous unit-0 binding, program, matrix stacks/mode, attribs and prior active texture unit. Preserve SDL viewport/scissor, blend/texture environment and tint/alpha conventions so the next ordinary `SDL_RenderCopy` is unaffected. Existing `DrawDamageBurst` does not explicitly restore the old unit-0 binding (`:270-333`) and is not a safe cleanup template.
