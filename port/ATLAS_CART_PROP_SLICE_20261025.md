# Opt-in static cart/track atlas — 2026-10-25

The authored-level XML inventory found 27 `cart_tracks.png` ordinary `Sprite` references across Forest-1/2/barn, Waterfall-top, cliff, grass, arena and shadow; five `objects/cart.png` references in cliff/village; and two `objects/cart_dark.png` in barn/shadow. Every selected reference is `effectlighttexture`, `repeatX=false`, `repeatY=false`, `isanimated=false`. The Waterfall-top cart-track IDs 70–73 and Forest-1 IDs 50–51 are moving-camera sample users. The runtime path is `LevelScene` ordinary `DrawSprite` through SDL's texture copy and the existing virtual source-rectangle mapping. `horse_tracks.png` is explicitly excluded: its two village references are `repeatX=true`, including a `Breakable`. Other prop textures are not implied eligible by their directory name; private-shader, UV-shift, repeat, foliage, particle and target paths remain exceptions pending individual audit. Even a virtual cart/track ID takes the dedicated original fallback for wrap/UV-shift/private shader requests.

`port/tools/cart_prop_atlas.py` produces one deterministic 1032×581 page, cropped to its occupied bounds, under the 4096 ceiling. The three full RGBA images occupy 554,300 of 599,592 page pixels (92.446% source-content occupancy); page storage is 2.40 MB raw RGBA. Full source rectangles are retained because transparent texels have nonzero hidden RGB; this makes reconstruction of **every** RGBA byte exact, including alpha-zero RGB, rather than only visible pixels. The PNG, manifest and lookup regenerated byte-identically on two passes. There is 2-pixel extruded padding. The opt-in environment variable is `DEATHLEAK_ATLAS_CART_PROPS=on`; normal loading remains unchanged.

The isolated build and reproducible capture/profile runners are under ignored `port/build/atlas-cart-props/`. The final build used current HEAD renderer plus only this opt-in mapping, excluding the unrelated unstaged raft-mip experiment.
