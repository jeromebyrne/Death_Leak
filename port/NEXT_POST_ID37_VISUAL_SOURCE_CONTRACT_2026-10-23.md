The documented D3DX default predicts a full generated mip chain (12 levels for 2048×512) after successful load, but the **actual bound SRV view range and sampled LOD have not been measured**; source alone must not be upgraded to a runtime observation.
- Linux `port/game/LevelScene.cpp:1225-1294` projects this quad at 2/3 scale and routes nonzero fractional UV shift to `DrawFractionalParallax`. `port/linux/SDLRenderer.cpp:349-469` binds the SDL texture, sets `GL_REPEAT` on S/T, `GL_LINEAR` minification and `GL_NEAREST` magnification, and draws the one-span float quad. The effective 2048→1365.33 and 512→341.33 projection is 1.5:1 minification, nominal LOD log2(1.5)≈0.585, where mip-linear sampling would blend levels 0 and 1 if exposed. These are Linux composition measurements, **not** evidence that mip filtering is a visible defect or that the corrected frame matches Windows. ## Smallest next discriminator and implementation boundary

1. **First decisive source-runtime gate:** on a runnable original Windows forest-1 build or shipped executable, at an identified ID37 draw, record the bound `ID3D10ShaderResourceView::GetDesc` (`MostDetailedMip`, view `MipLevels`) and underlying `ID3D10Texture2D::GetDesc` (`Width`, `Height`, resource `MipLevels`), plus observed sample LOD at a registered camera/viewport/UV state. Merely finding resource level 1 is insufficient if the SRV excludes it; a null D3DX load-info argument is not a runtime descriptor. If the bound view exposes only level 0 or the sample uses only level 0, close this candidate without a port edit.
2. If Windows demonstrably blends level 1, the smallest Linux-side experiment is an **isolated ID37-only**, same-frame, same-camera, lossless GPU A/B: current base-level float draw versus a temporary ID37-only generated-mip + `GL_LINEAR_MIPMAP_LINEAR` min state, with wrap, UV, alpha, tint, position, painter order and sepia unchanged. Keep the change only after the *same-state Windows* crop improves; a Linux A/B by itself proves sensitivity, not parity. Do not apply a renderer-wide mip toggle or edit XML/art/ID37 opacity.
3. If an original runtime remains unavailable, a read-only CPU PNG mip/footprint estimate can cheaply bound potential edge signal, but cannot establish D3D generated texels, GL filtering or a visible Windows mismatch. Report the blocker and leave source unchanged.
