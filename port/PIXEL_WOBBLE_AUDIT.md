# Forest-1 pixel-wobble fog parity audit (read-only, 2026-10-22)

## Source contract

- `Game/XmlFiles/levels/forest_exploration_1.xml:1631-1662` authors `ScrollingSprite` IDs **119** and **122** as 1988×1290 `Media/fog.png`, `kGroundFront`, rotation 0.11, respective base alphas **0.5/0.6**, and `effectpixelwobble` intensity **0.07**, speed modifier **0.3**. ID119 has no vertical flip; ID122 has `verticalflip=true`. Both disable player-occlusion fade. Their respective X scrolls are +1000/45 s and −750/70 s, each with a 6 s fade-in/out.
- Original `ScrollingSprite::Update` (`Game/src/GameObjects/ScrollingSprite.cpp:23-59`) controls position and per-sprite alpha. `DrawableObject::Initialise` captures the XML alpha (`:214-219`); `Sprite::Draw_effectPixelWobble` passes *current* `m_alpha` plus each sprite's intensity/speed (`Game/src/GameObjects/Sprite.cpp:675-688`). Thus the effect does not replace or add a second alpha fade.
- The shader (`Game/ShaderFiles/BasicLightTexture_PixelWobble.fx:13-19,56-64`) transforms **sample coordinates, not geometry**. In order, `v1 = v + sin(u * (Time * SpeedMod)) * Intensity`, then `u1 = u + sin(v1 * (Time * SpeedMod)) * Intensity`. It samples the diffuse RGBA texture at `(u1,v1)` with **wrap U/V** and `MIN_LINEAR_MAG_POINT_MIP_LINEAR`, then returns unchanged sampled RGB and `sample.a * alpha`. The second sine uses the *already-perturbed* V; replacing these with independent or additive-time waves changes the image. Displacement is at most 0.07 UV, i.e. about 139 source texels for this 1988-pixel fog texture, so it can materially move fog edges/interior alpha.
- `Time` is **not** global elapsed seconds: `Game/src/Game.cpp:379-401` advances a static effect clock with the last update delta until it exceeds 10 s, then decrements to below 5 s, repeating the 5–10 s shuttle. The first span begins at zero. `ReverseMotion()` negates the effect's current intensity and speed (`EffectLightTexturePixelWobble.cpp:27-35`), but `Sprite::Draw_effectPixelWobble` sets both from XML for *every* sprite draw afterward. Consequently these fog draws use positive 0.07/0.3, while the shuttling Time persists. Do not implement a continuously increasing global clock or sustained negative XML parameters for this effect. `Game.cpp:371-375` uses a separate total-time clock for other shaders.
- Original sprite vertices assign V=0 to the world-bottom and V=1 to the world-top (`Sprite.cpp:19-22,215-222`); `Camera2D.cpp:27-30` projects positive Y upward. A parity implementation must account for that UV orientation and ID122's vertical flip before the above UV perturbation; simply applying the formula to SDL screen-top-down V may invert the distortion/texture placement. This is a coordinate-contract observation, not a claim of matched original pixels.

## Current Linux behavior (do not re-implement)

- `port/game/LevelScene.h:11-37` and `LevelScene.cpp:450-464,585-621` **already parse and execute** `ScrollingSprite` motion, 6 s fades, update-zone pause, endpoint reset/skip, and XML-original-alpha retention for all such sprites. `LevelScene.cpp:755,759,764` passes current tint alpha, authored flips/rotation, and current XY to the renderer. `port/SCROLLING_FOG_CHECKPOINT.md` records a focused host test of this lane. The older `port/FOREST_PATCH_AUDIT.md:11-18` describes a pre-fix HEAD and its recommendation to add scroll/fade is stale.
- `port/game/LevelScene.cpp:432-464` only recognizes `effectfoliagesway`; it does **not** parse pixel-wobble intensity/speed. `port/render/Renderer.h:20-43` has no pixel-wobble sprite state. `port/linux/SDLRenderer.cpp:185-229` uses SDL alpha/color modulation and ordinary `SDL_RenderCopy*` for these fog sprites; its existing foliage-sway and parallax/repeat paths do not distort fog texture coordinates. Therefore IDs 119/122 now move and fade, but sample an un-wobbled texture.
- SDL's existing `tint.a` applies the port's dynamic sprite fade to sampled texture alpha, approximately matching the source's `sample.a * alpha` before blending, with 8-bit quantization. The original color blend is source-alpha over destination (`Game/src/Core/Graphics.cpp:392-407`). Preserve this alpha path; do not multiply sampled RGB by the fade or bake an alpha-modified fog asset. The shader changes which RGBA texel is sampled, including its alpha, so correct fade alone cannot reproduce its moving opacity pattern.

2. Add a **per-sprite GPU sampling path** before the ordinary SDL copy that implements the source's ordered `(u,v)` equations, wrap sampler, authored flip/rotation, and current sprite alpha. Feed the original effect's 0→10→5→10… clock (delta and strict threshold semantics above), shared across draws, independently of each sprite's 45/70 s scrolling cycle. Keep fog draw order and the scene sepia pass unchanged. On SDL/OpenGL, any custom draw must respect SDL batch flush/state restoration around direct GL work, as the existing sepia pass does (`SDLRenderer.cpp:306-354`). A uniform transform, quad deformation, parallax shift, or an extra fade is not equivalent to this per-fragment sample.

Review deterministic same-frame baseline versus wobble-only/hide-ID119/122 renders at fresh-start ~1, 5, >6 and >10 s, with identical camera, route, sepia and physical-GPU path; compare against an original Windows frame if available.
