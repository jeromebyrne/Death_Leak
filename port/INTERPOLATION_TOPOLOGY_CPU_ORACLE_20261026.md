## Concrete oracle and result

`port/linux/InterpolationTopologyOracle.h` is an independent CPU admission/sampling primitive. It keys a painter item by nonzero object ID plus generation (to prevent particle-slot reuse), scene epoch, original painter ordinal, visibility, world position and per-item camera factors. It rejects duplicate/missing identities, nonfinite geometry, and invalid painter order; it holds the **entire current family**, projected with current camera, at births, deaths, visibility changes, ordinal changes, epoch/camera cuts and large unmarked jumps. Only stable same-order topology interpolates world positions and one coherent camera sample. This deliberately avoids a partially lerped body with newly born spray or an old arm against a new shadow. The 250-world-unit unmarked-jump threshold is an oracle fixture guard, not a calibrated runtime teleport rule.

## Why runtime B fails the gate

`SceneSprite` has authored `order` and flags, but no scene-epoch-scoped semantic stable ID; `ParticleSpray::Particle` has no stable ID or generation at all. The test compiles source-type assertions for these missing fields. `LevelScene::Draw` interleaves authored objects, dynamics and attached sprays by depth/order, while arm/shadow/aim/prompt visibility and spray vector cardinality change. The only `PresentationRecordingRenderer` packet is cleared at `BeginFrame`, has no per-command semantic identity, and ordinary frames present current state while refresh-only slots replay that same packet. The oracle's synthetic items cannot be mapped soundly to **actual** current/previous draw commands. A naive B would either mispair particles, detach effects, violate painter order, or rewind on the first repeat after an ordinary current-state present. Consequently there is no production candidate to submit to an A/B/A GPU pixel/timing gate; the successful build and CPU test are **not** interpolation or high-Hz acceptance.
