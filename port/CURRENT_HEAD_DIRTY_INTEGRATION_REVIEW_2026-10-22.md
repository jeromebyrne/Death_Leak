2. **Blood can visually pass through a nonpierceable/unknown line and splat on a later pierceable line.** `Combat.cpp:371-383` discards nonpierceable/unknown material segments *before* choosing the earliest sweep winner, then `:385-399` splats whichever eligible line remains. Add a two-line front-nonpierceable/back-pierceable CPU fixture. Keep `SolidBox` outside this line path and label source collision-order differences honestly.

3. **Live opposed-stick aim line can face away from the strafe body.** Right-stick input reaches `main.cpp:671-673,689-695` and `LevelScene::UpdatePlayerVisual` at `main.cpp:1101-1104`; `LevelScene.cpp:1100-1104` turns the strafe body to `strafe.aimFacing`, but `:1085` stores the movement `facing` for the aim line, and `:1217,1272` place/flip it using that movement-facing value.
