- Position/ordering: Windows `ParallaxLayer::Update` calls `Sprite::Update` before assigning followed camera X (`Game/src/GameObjects/ParallaxLayer.cpp:26-35`); Linux computes current camera X when drawing (`port/game/LevelScene.cpp:1233-1261`). Both order by descending depth (`Game/src/GameObjects/GameObjectManager.cpp:58-64,1021-1025`; `port/game/LevelScene.cpp:1200-1231`). No new draw-order or vertical-placement discrepancy is supported here.
- Color/effect: Windows shader multiplies sampled RGBA by `lightColor` then alpha by `m_alpha` (`BasicLightTexture.fx:53-59`; `Game/src/GameObjects/Sprite.cpp:626-648`). `EffectLightTexture::Load` initializes light color to `(1,1,1,1)` (`Game/src/Effects/EffectLightTexture.cpp:43-45`), while `Sprite::Draw_effectLightTexture` resets it to unity after drawing (`Sprite.cpp:672`). The one-byte alpha quantization residual remains as noted in the alpha-fix report; it is bounded, not the next high-impact candidate.
