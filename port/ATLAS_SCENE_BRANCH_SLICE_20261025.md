# Opt-in ordinary scene branch atlas — 2026-10-25

Scope: all six `Game/Media/objects/branch_1..6.png` textures. XML inventory across levels finds 16 authored references, all ordinary `Sprite`, `effectlighttexture`, `repeatX=false`; Forest-1 IDs 27–31 and Waterfall-top IDs 52–54 are actual scene users. Forest moving-camera sample B:180 traverses the ID29–31 x≈965–1814 branch group, including rotated ID31; B:360 checks subsequent camera state. No asset is selected merely by directory.

The existing deterministic packer emits a single 1746×607 RGBA page (4.24 MB uncompressed), trimmed to occupied bounds under the 4096 ceiling, with two-pixel edge extrusion, source hashes and source-rectangle manifest. Six reconstructed RGBA crops match source bytes; regeneration of PNG/JSON/TSV is byte-identical. Source content occupies 738,691/1,059,822 page pixels (69.7%). The opt-in `DEATHLEAK_ATLAS_SCENE_BRANCHES=on` maps each authored path to a virtual source rectangle on this one page. A trace proves one page load and no branch dedicated loads in the Forest route; normal control uses six dedicated textures. Runtime repeat/UV-shift/pixel-wobble/foliage/damage cases already fall back to a dedicated original texture. No page is loaded unless this family is requested.

Excluded from this slice: repeated ground/tree-strip/shrubbery textures; fractional-parallax backgrounds/waterfall; pixel-wobble fog/waterfall; foliage-sway trees/rope ends; particle-spray assets; render targets. Their wrap, private-GL sampler, shader, or residency contracts require separate treatment. Ordinary branches retain authored tint, alpha, flips, rotation, source dimensions and painter order.

Isolated Docker build used HEAD renderer plus only this mapping; unrelated unstaged raft-mip renderer work was excluded. Serial physical Xorg `:0`, nouveau NVE7, SDL x11/OpenGL accelerated=1/software=0, 1280×720, fixed-dt Forest B:180 and B:360 control/candidate/control captures: all three RGBA images are byte-identical at each endpoint (0 changed pixels). Gameplay endpoints matched: B:180 x=1368.99, 5 orbs, 25 health; B:360 x=2808.99, 7 orbs, 25 health. Evidence and reproducible runners: ignored `port/build/atlas-scene-branches/`.

Clean serial B:360 profiled controls/candidate/control, 120 warmup + 240 measured physical-display frames: p50/p95/p99 ms **20.114/21.992/22.124**, **20.195/22.057/22.165**, **20.110/22.012/22.103**. This small candidate slowdown is not a demonstrated FPS gain. Renderer logical `DrawSprite` call counts were **31,461/31,461/31,461**; actual SDL GPU submissions and texture binds are not exposed by this counter, so no batching/bind reduction is claimed. A candidate-only texture-load trace (separate from the clean A/B) confirmed the atlas page load. This opt-in coverage slice does not establish 60 FPS, 8K, high refresh or release acceptance.
