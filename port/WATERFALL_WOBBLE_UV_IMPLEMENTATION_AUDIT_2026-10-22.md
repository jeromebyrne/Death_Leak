# Waterfall IDs 13/14: wobble/autoscroll UV implementation audit — 2026-10-22

**Boundary:** Source-only, read-only audit of code/XML/tests and prior evidence. No source, test, checkpoint, build, GPU, or commit changes. This report is the sole file written. Finding: the Linux draw contract carries the authored V phase, but its selected GL pixel-wobble branch drops that phase. This is independently confirmed from the current files; it is not a claim of measured Windows/Linux visual divergence.

## Exact contract and seam

- `Game/XmlFiles/levels/waterfall_top.xml:261-307`: IDs 13 and 14 are `ParallaxLayer`s using `Media/waterfall_4.png`, `effectpixelwobble` (intensity **0.005**, speed modifier **10**), `autoscrolly=true` at speed **11**, alpha **0.3**, horizontal flip **true**, vertical flip **false**, and no camera-Y follow/parallax. Both quads are 810.662903 × 1621.325806 authored units and remain at `kGroundBack`.
- Windows `Game/src/GameObjects/ParallaxLayer.cpp:114-155` advances the non-bump vertex V phase by `speed * .001 * lastUpdateDelta/targetDelta` on draw, regardless of the pixel-wobble effect. Vertices 0/1 are world-bottom with V=`phase`; 2/3 are world-top with V=`phase+1` (`Sprite.cpp:194-230`). `Sprite.cpp:675-710` uses the same vertex buffer for pixel wobble. `Game/ShaderFiles/BasicLightTexture_PixelWobble.fx:55-66` first adds `sin(U * Time * SpeedMod)*Intensity` to V, then adds `sin(modified V * Time * SpeedMod)*Intensity` to U, then samples wrapped UV. Thus the flow phase must be present **before both wobble operations**, especially before the second sine.
- Linux `port/game/LevelScene.cpp:371-372,742-749,983-989,1005-1009` parses, advances, and sends `autoScrollYPhase` as `render::Sprite::uvShiftY` while retaining the wobble state. At `dt=1/60` the port's 720/1080 scale gives `11*(2/3)*.001 = 0.007333333` V per update, or **0.44** after 60 updates, modulo one. `port/tests/waterfall_autoscroll_test.cpp:24-67` checks phase on all eight drawn sheets, but stops at the capture-renderer contract; it never exercises SDL/GL pixel-wobble sampling.
- `port/linux/SDLRenderer.cpp:207-212` selects `DrawPixelWobble` before the ordinary wrapped-copy branch at `:228-244`. `DrawPixelWobble` (`:317-375`) emits corner UV from flip flags only and never accesses either `uvShiftY` or `uvShiftX`; GLSL (`:609-623`) consequently wobbles and samples unshifted UV. For IDs 13/14 this makes local wobble animate while the authored V-flow does not. The GL branch already uses `GL_REPEAT`, linear minification, nearest magnification, per-sprite opacity and blending (`:327-351`); preserving these is part of a narrow fix. Routing these IDs into SDL copies would lose the shader effect.

## Sign/orientation, stated as an implementation invariant

`ParallaxLayer.cpp` assigns **V=phase+1 at world/screen top** and **V=phase at bottom** for these vertically unflipped sprites. Linux GL corners already provide top V=1, bottom V=0 (`SDLRenderer.cpp:357-365`), and its GLSL converts authored V to SDL-uploaded texture T with `1.0-uv.y` (`:617-622`; first PNG row is T=0). Therefore the correct input to the wobble math is **`uv.y = baseV + sprite.uvShiftY`**: add the positive phase to both top and bottom authored V, either as a shader uniform applied immediately after reading `gl_TexCoord[0]` or in both corner V values. Do **not** negate the phase at that point and do **not** apply it only after wobble. At zero wobble intensity, the sampled PNG-row coordinate is `fract(1 - (baseV + phase))`, i.e. at screen-down fraction `s`, **`fract(s - phase)`**. Increasing positive phase therefore makes a fixed texture feature travel **down** the screen, matching the existing ordinary-sheet wrap path. At one update the expected screen displacement on either ID's 1080.883871-pixel port quad is about **+7.9265 px**; 60 updates give **+475.589 px** modulo a full-height repeat. Horizontal flip only reverses U and must not invert this V sign. For future X scroll, its phase must likewise enter authored U before wobble; IDs 13/14 have no X scroll, so that is outside this slice.
